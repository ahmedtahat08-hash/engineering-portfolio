# Matrix Calculator in C

## Overview

This project is a menu-driven matrix calculator developed in C. The program allows the user to perform matrix addition/subtraction, matrix multiplication, matrix transpose, and simultaneous linear equation solving.

The project focuses on C programming, functions, 2D arrays, loops, input validation, dimensional compatibility checks, and numerical problem solving.

**Project Report:** [View PDF](matrix-calculator-c-final-report.pdf)

## Key Skills

C Programming, 2D Arrays, Functions, Nested Loops, Input Validation, Matrix Operations, Gaussian Elimination, Modular Programming, Numerical Methods

## Project Features

- Built an interactive menu-driven C program for multiple matrix operations.
- Implemented matrix addition/subtraction, matrix multiplication, matrix transpose, and simultaneous linear equation solving.
- Used modular functions to separate each operation and improve code organization.
- Added dimensional compatibility checks to prevent invalid matrix operations.
- Implemented Gaussian elimination with forward elimination and back substitution.
- Used a reusable `printMatrix()` helper function to format matrix output clearly.
