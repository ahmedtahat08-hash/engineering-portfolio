# FPGA-Based Car Parking System

## Overview

This project is a Digital Circuits lab design for an automated two-floor parking garage system. The system uses parking spot sensor inputs to detect space availability, control the entrance gate, assign parking locations, and display the correct floor and parking spot number.

The garage has two floors with 8 parking spaces on each floor, for a total of 16 parking spaces. The system prevents the gate from opening when the garage is full and assigns parking in order to reduce congestion.

## Key Skills

Digital Logic, FPGA Design Concepts, Verilog/System Design, Boolean Logic, Sensor-Based Control, Seven-Segment Display, Gate Control

## Project Highlights

- Designed an FPGA-based digital parking system concept using sensor inputs to control gate access.
- Developed logic for a two-floor parking garage with 16 total parking spaces.
- Used parking spot sensor inputs to detect whether the garage had available spaces.
- Designed gate control conditions to prevent entry when the garage is full.
- Included floor selection and parking spot display using a seven-segment display.
